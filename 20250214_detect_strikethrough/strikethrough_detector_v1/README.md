# 취소선 검출 파이썬 코드 (v1)

## 설명

파이썬으로 구현한 취소선 검출 코드입니다.
claude 를 사용해서 검출 코드를 생성했습니다.

## 사용법

아래 명령은 입력 폴더내의 모든 텍스트 이미지에 대해 취소선 검출을 수행합니다. 결과 이미지는 `result_image` 폴더에 저장됩니다.

```bash
python strikethrough_detector.py -i sample/strikethrough/ -r result_image

# -i : 입력 폴더
# -r : 결과 이미지 저장 폴더
```
